# Password Strength Checker

## Description

A command-line tool that checks password strength using its length, presence of digits, uppercase letters, and selected symbols. It also checks whether the password exactly matches an entry in the supplied list of 100,000 common passwords. Passwords are rated Very Weak, Weak, Medium, Strong, or Very Strong.

## How to Run

python3 project1.py

Enter a password when prompted. You can check multiple passwords in one session before exiting.
