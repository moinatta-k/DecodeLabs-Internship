# Caesar Cipher Encryption & Decryption

## Description

A command-line tool that encrypts and decrypts text using a Caesar cipher. The user can choose their own shift key. It correctly handles both uppercase and lowercase letters, and leaves spaces and punctuation unchanged.

## How to Run

python3 project2.py

Enter a message and a numeric shift key when prompted. The program will show both the encrypted and decrypted versions, and you can repeat this for multiple messages.
