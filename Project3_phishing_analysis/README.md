# Phishing Awareness Analysis

## Description

An analytical security project that identifies red flags in phishing emails and provides a practical triage system. Includes a checklist of warning signs, a two-tier severity model, a decision tree for classifying messages as Safe, Suspicious, or Malicious, and two fully worked examples analyzing realistic phishing samples.

## How to Use

Open `triage_checklist.md` and work through the seven checklist questions for any suspicious message. Check the Tier 1 list first — a single "yes" there is enough to call a message Malicious on its own. Otherwise, count how many of the remaining questions are "yes" and follow the decision tree to reach a final verdict: Close (Safe), Warn User (Suspicious), or Block & Escalate (Malicious).
