# DecodeLabs Internship — Cyber Security Track

This repository contains my completed projects for the DecodeLabs Internship (Batch 2026), Cyber Security track. Each project is self-contained in its own folder with source code and a dedicated README.

## Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | [Password Strength Checker](./Project1_password_checker) | Evaluates password strength using length, character variety, and a 100,000-entry breached-password blocklist. |
| 2 | [Caesar Cipher Encryption/Decryption](./Project2_encryption_decryption) | Encrypts and decrypts text using a customizable-shift Caesar cipher, supporting upper and lowercase letters. |
| 3 | [Phishing Awareness Analysis](./Project3_phishing_analysis) | Identifies red flags in phishing emails and provides a triage checklist and decision tree for classifying threats. |
| 4 | [System Vulnerability Checklist](./Project4_vulnerability_checklist) | Performs a live security audit covering password risk, pending OS updates, and common user security habits, then outputs a weighted risk report. |
